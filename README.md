### 第一条 软件功能与许可范围

1. **软件定位**：本应用是一款专为 Android 设备研发的专业音频数字信号处理（DSP）与均衡调节工具。
2. **技术方案与权限说明**：
   * 本应用使用 Android 系统的 `AudioPlaybackCapture` API 和系统媒体投影（`MediaProjection`）服务进行系统音频路由捕获。**在此郑重说明：申请媒体投影权限仅为获取系统底层音频捕获授权，本应用绝不截取、录制、存储或上传您的屏幕图像及画面内容。**
3. **第三方工具（Shizuku）辅助说明**：
   * 本应用的部分高级特性依赖于第三方服务工具 Shizuku。用户需自行决定是否安装、配置并授权 Shizuku。

### 第四条 隐私保护与联网行为说明

1. **本地化音频处理**：**本应用对所有音频信号的 DSP、均衡、卷积及空间音频运算均 100% 在用户设备本地即时处理完成。本应用绝不录音、绝不离线保存、绝不上演、分析或上传用户的任何音频流、通话记录或隐私数据。**
2. **有限的联网范围**：本应用的联网行为仅限于以下必要场景：
   * 校验支付订单状态及激活高级版权益；
   * 从指定的公开合规在线仓库拉取/更新耳机与设备的校准曲线数据；
   * 必要的应用版本更新检测与关键错误日志上报。
3. **关于隐私政策**：有关个人信息处理的具体规则与权限调用详情，请参阅与本协议同等法律效力的《隐私政策》。

### 第五条 免责声明（重要）

1. **【硬件安全免责】**：**DSP 音频处理涉及增益放大（Gain Boost）、频段补偿及滤波操作。若用户设置过大增益或不当的超低频/超高频参数，极端情况下可能引起扬声器、耳机单元震膜破裂或元器件物理损坏。用户在调谐参数时应遵循科学原则并控制输出电平。开发者对任何因参数设置不当导致的耳机、音响或播放设备硬件损毁不承担任何赔偿责任。**
2. **【听力健康免责】**：**长时间、高声压级（高音量）聆听音频可能导致不可逆的听力损伤。用户须自行监控播放音量并合理控制聆听时长。开发者不对任何因使用本软件引发的听力下降、耳鸣等身体健康问题承担法律责任。**
3. **【兼容性与系统差异免责】**：Android 生态具有高度碎片化特性，各品牌定制系统（ROM）对后台进程管理、音频通路路由及电池优化策略差异巨大。开发者无法保证本应用在所有机型、所有系统版本及所有第三方播放器上均能稳定工作；因系统杀后台、厂商特定音频冲突导致的断流或失效，不属于本应用违约或质量缺陷。
